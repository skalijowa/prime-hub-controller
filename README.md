# Spike × Xbox Code Maker

A small web app that writes a **Pybricks** program for a **LEGO SPIKE Prime** hub that is driven by an **Xbox controller**.

Pick what is plugged into each port, choose which controller button or stick drives which motor, add a few "when this happens → do this" rules, and copy the finished Python code into [code.pybricks.com](https://code.pybricks.com). No coding needed.

It is a single file (`index.html`) with no dependencies and no build step. It works offline once opened and does not send any data anywhere.

## What it can do

1. **Hub setup:** set ports A–F to Motor, Color Sensor, Distance Sensor or Force Sensor, and flip the direction of a motor.
2. **Controller → motors:** map sticks, triggers, buttons and the D-pad to motors.
   - Sticks and triggers drive a motor smoothly.
   - Buttons can run a motor while held, start or stop it with a press, or reset its angle.
   - Set speed per mapping, and reverse it if needed.
3. **Rules (when → then):**
   - **When:** a controller button or trigger, or a hub sensor (distance, force, color, reflection).
   - **Then:** show a picture on the 5×5 light matrix (draw your own), light or blink the hub light, beep, rumble the controller, or stop motors.
   - Stop rules can stop only while the trigger is active, block only forward movement, or stay stopped until the stick is pushed forward again.
4. **Settings:** maximum speed, stick dead zone, idle behaviour of the motors (brake, coast, hold), controller name, and an option to invert the up/down direction of both sticks.
5. **Load existing code:** paste a program into the box at the top and the app fills in the settings so you can keep editing it.

## How to use it

1. Open the app (see [Hosting on GitHub Pages](#hosting-on-github-pages) below, or just open `index.html` in a browser).
2. Fill in steps 1–4.
3. Press **Copy code** in step 5.
4. Go to [code.pybricks.com](https://code.pybricks.com) in Chrome or Edge, create a new program, paste the code, connect the hub and press **Run**.

### Before the first run

- Install the **Pybricks firmware** on the SPIKE hub (done once from code.pybricks.com).
- Pair the controller: turn it on, then hold the small **pairing button** on the back edge next to the USB-C port until the Xbox logo blinks fast. Start the program on the hub. The Xbox button stays lit when connected.
- A controller only remembers the most recently paired device. If it was used with a console or another hub in between, pair it again.
- The program waits 10 seconds for the controller before giving up.

### If something goes wrong

- **The car drives backwards when you push the stick forward.** Use any one of these:
  - tick **Reverse** on the mapping,
  - flip the motor direction button in step 1,
  - tick **Invert up/down on both sticks** in Settings.
- **The controller does not connect.** Update its firmware with the *Xbox Accessories* app, then pair it again.
- **Loading code does not understand something.** The app writes the code again from its settings, so hand-written extras (own functions, extra loops) are not kept. Rules it cannot understand are left out, and the app says how many.

## Loading existing code

Code generated by this app ends with a line starting with `# CM1`. It holds the settings so the program can be loaded back exactly. Please keep that line if you want to load the program later. Programs without that line are read from their structure, which works for code made by this app but only partly for code written by hand.

## Hosting on GitHub Pages

1. Create a repository and add `index.html` (and this `README.md`).
2. Open **Settings → Pages**.
3. Under *Build and deployment* choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then save.
4. After a minute or two the app is available at `https://<your-user>.github.io/<repository>/`.

Opening `index.html` directly from your computer also works.

## Notes

- Made for the SPIKE Prime / Inventor hub (`PrimeHub`) and Xbox controllers supported by Pybricks, such as the Xbox Series Wireless Controller.
- The generated code was written from the Pybricks documentation and checked with simulated input. It has not been tested on every hardware combination, so try a new program with the motors disconnected from the model first.
- The Distance Sensor reports millimetres in Pybricks. The app takes centimetres and converts them.
- Pybricks documentation: <https://docs.pybricks.com/en/latest/iodevices/xboxcontroller.html>
