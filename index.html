Spike Prime × Xbox Code Maker

Set up your hub, map the controller, copy the Pybricks code.

📥 Already have a program? Paste it here to keep editing it

Paste your current Pybricks code and press Load. The app fills in the ports, controller mappings and rules below. Code made by this app is understood best. Anything hand-written (own functions, extra loops) is not kept, because the app writes the code again from the settings. Loading replaces what is set now.

1Your SPIKE Prime hub

Choose what is plugged into each port. Use the direction button to flip a motor that is mounted the other way round.

2Controller → motors

Each card connects one control on the Xbox controller to one motor. Several cards can drive the same motor (e.g. right trigger = forward, left trigger = backward). Car drives the wrong way? Tick Reverse on that card, flip the motor with its direction button in step 1, or use “Invert up/down on both sticks” in step 4.

3When this happens → do this

Pick a trigger (a controller button, or a sensor you added in step 1: set a port to Color, Distance or Force) and what should happen: light up the hub’s 5×5 display, blink the light, beep, rumble the controller or stop motors.

4Settings

5Your Pybricks program
