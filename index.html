Spike Prime × Xbox Code Maker

Pick your motors, map the controller, copy the Pybricks code.

1Your SPIKE Prime hub

Choose what is plugged into each port: a motor, a Color Sensor, a Distance Sensor or a Force Sensor. Use the direction button to flip a motor that is mounted the other way round.

2Controller mapping

Each line connects one control on the Xbox controller to one motor. Several lines can drive the same motor (e.g. right trigger = forward, left trigger = backward).

3Sensor rules

Make the robot react to its sensors, e.g. “Distance Sensor is closer than 15 cm → stop all motors”.

4Settings

5Your Pybricks program

The code updates automatically while you change things above.
