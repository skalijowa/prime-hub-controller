Spike Prime × Xbox Code Maker

Set up your hub, map the controller, copy the Pybricks code.

1Your SPIKE Prime hub

Choose what is plugged into each port. Use the direction button to flip a motor that is mounted the other way round.

2Controller → motors

Each card connects one control on the Xbox controller to one motor. Several cards can drive the same motor (e.g. right trigger = forward, left trigger = backward).

3When this happens → do this

Pick a trigger (a controller button, or a sensor you added in step 1: set a port to Color, Distance or Force) and what should happen: light up the hub’s 5×5 display, blink the light, beep, rumble the controller or stop motors.

4Settings

5Your Pybricks program

The code updates automatically while you change things above.
